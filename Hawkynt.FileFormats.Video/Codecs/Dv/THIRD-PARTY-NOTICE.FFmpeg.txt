Files used:

  libavcodec/dvdec.c            the block layer, the three-pass overflow read,
                                the inverse weighting tables and the macroblock
                                placement
  libavcodec/dvenc.c            the class-number assignment, the quantisation
                                search, the forward weighting table and the DIF
                                frame layout
  libavcodec/dv.c               dv_calc_mb_coordinates and the video-segment walk
  libavcodec/dvdata.c           the 2-4-8 scan, the quantiser shift table and the
                                run-level code book
  libavcodec/dvdata.h           NB_DV_VLC and the code book's declarations
  libavcodec/dv.h               the DIF section and pack identifiers
  libavcodec/dv_profile.c       the profile table and profile identification
  libavcodec/dv_profile.h       the profile record
  libavcodec/dv_internal.h      the video-segment work chunk
  libavcodec/dv_tablegen.h      the construction of the encoder's code table
  libavcodec/simple_idct.c      ff_simple_idct248_put and its 4-point column pass
  libavcodec/simple_idct_template.c  the 8-point row and column passes
  libavcodec/jfdctint_template.c     the forward transform the encoder uses
  libavcodec/mathtables.c       ff_zigzag_direct
