The Lagarith decoder in this directory is converted from FFmpeg (https://github.com/FFmpeg/FFmpeg):

  libavcodec/lagarith.c      the frame types and their plane layouts, the probability header with its
                             variable-length code and soft-float rescaling, the four plane codings,
                             the zero-run escape, and the three predictors
  libavcodec/lagarithrac.c   the range decoder's initialisation
  libavcodec/lagarithrac.h   the range decoder

The algorithms are carried across into managed C#, not vendored. The probability header's code table
is reproduced exactly because it is fixed codec data required for interoperability. The encoder — the
predictors run forwards, the probability table written, and the range encoder — is this package's own.
