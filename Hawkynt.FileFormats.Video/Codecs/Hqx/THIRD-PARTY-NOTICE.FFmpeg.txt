The Canopus HQX decoder in this directory is converted from FFmpeg (https://github.com/FFmpeg/FFmpeg):

  libavcodec/hqx.c        the frame and slice layout, the macroblock order, the layouts and quantisers
  libavcodec/hqxdsp.c     the inverse transform
  libavcodec/hqxvlc.h     the DC and AC code tables
  libavcodec/hq_common.c  the coded-block-pattern code
  libavcodec/mathtables.c ff_zigzag_direct

  The FFmpeg developers; these files carry no copyright line of their own.

option) any later version. This work is distributed under the GNU Lesser General Public License
version 3 or later, which the "or later" clause permits; the licence text is in LICENSE at the root of
this repository.

The algorithms are carried across into managed C#, not vendored. The tables in HqxTables.cs were
transcribed mechanically, by a script that parsed the C initialisers, and are reproduced exactly because
they are fixed data required for interoperability. The encoder is this package's own.
