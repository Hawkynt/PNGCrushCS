The code tables in MsMpeg4Data.cs, and the bitstream syntax the rest of this
directory implements, are taken from FFmpeg (https://ffmpeg.org), which is
where Microsoft's three MPEG-4 variants were reverse-engineered and where the
only authoritative statement of their tables exists. Microsoft published no
specification for any of them.

Files used, all from libavcodec:

  msmpeg4data.c        run-level tables 0, 1, 3 and 4; the predicted-picture
                       macroblock table of version 3; the macroblock type and
                       intra chrominance pattern tables of version 2; both
                       motion vector tables of version 3
  msmpeg4_vc1_data.c   the intra-picture coded block pattern table and both
                       DC tables of version 3
  h263data.c           run-level table 5; CBPY; the motion vector magnitudes;
                       the intra and inter MCBPC tables version 1 borrows
  mpeg4data.h          run-level table 2; the DC size tables versions 1 and 2
                       invert to make their own
  msmpeg4.c            the DC predictor, the coded block pattern predictor and
                       the construction of the version 1 and 2 DC tables
  msmpeg4dec.c         the picture header, the macroblock layer of all three
                       versions, the block layer and its three escape forms,
                       and the motion vector decoding
  msmpeg4enc.c         the encoder's table choices, its coded block pattern
                       prediction and its escape selection
  rl.c                 the derivation of the largest level per run and the
                       largest run per level from a run-level table
  h263.c               the motion vector predictor
  h263dec.c            the slice loop and the trailing extension header
