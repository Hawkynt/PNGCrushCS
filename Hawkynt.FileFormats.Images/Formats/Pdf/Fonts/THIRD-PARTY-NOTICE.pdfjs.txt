Parts of the code in this folder are converted from pdf.js
(https://github.com/mozilla/pdf.js), Copyright 2012-2016 Mozilla Foundation,
licensed under the Apache License, Version 2.0.

Converted from pdf.js (src/core/):

  font_renderer.js  compileCharString (Type 2 charstring outlines)
                      -> CffCharStringInterpreter.cs
                    compileGlyf (TrueType glyf outlines), parseCmap, lookupCmap
                      -> TrueTypeFontProgram.cs
  cff_parser.js     CFFParser: header, INDEX, DICT, charsets, encodings, FDSelect,
                    Private DICT and Subrs handling
                      -> CffFontProgram.cs
  type1_parser.js   Type1Parser: eexec and charstring decryption, the token scanner,
                    Encoding, Subrs and CharStrings extraction; Type1CharString
                    operator semantics (flex, hint replacement, seac, sbw, div)
                      -> Type1FontProgram.cs, Type1CharStringInterpreter.cs

Tables copied verbatim (values unchanged):

  cff_parser.js     CFFStandardStrings              -> CffStandardStrings.cs
  charsets.js       ISOAdobeCharset, ExpertCharset,
                    ExpertSubsetCharset             -> CffCharsets.cs
  encodings.js      StandardEncoding                -> FontEncodingStandard.cs
                    ExpertEncoding                  -> CffCharsets.cs
  fonts_utils.js    MacStandardGlyphOrdering        -> TrueTypeMacGlyphNames.cs

Changes: rewritten in C#; outlines are produced directly as move/line/cubic
verbs instead of pdf.js's command buffers; Type 1 charstrings are interpreted
directly rather than converted to Type 2 first; the optional Type 2 width
operand is read as the glyph advance; TrueType composites honour point matching
and outlines are placed at the hmtx phantom point (taken from the component
flagged USE_MY_METRICS where there is one), matching FreeType.
