Third-party artwork shipped with Crush.Viewer
=============================================

The icons under this directory were not drawn for this project. They come from two
published sets, unchanged, and each carries its own licence. Both licences require
that the notice travel with the artwork, which is what this file is for.

Why these two
-------------

Silk is the mid-2000s Windows look the viewer is going for and covers a picture
browser's whole vocabulary, but it exists only at 16x16, which is the size the
ribbon's small items and the status bar draw at. The ribbon's large items draw at
32x32, so they are Oxygen's, which is the same era's glossy style at that size
under a licence this repository can absorb without a second thought. Neither set is
scaled up: an icon is used at the size it was drawn for, and the one 32x32 icon
borrowed for a 16x16 slot (measure.png, for the rulers toggle) is box-filtered down
rather than sampled.

Commands with no honest icon in either set — a half-turn rotation, inverting the
colours, and the four display-filter choices, which name signal standards no icon
set distinguishes — are left as text rather than given a glyph that means something
else.
