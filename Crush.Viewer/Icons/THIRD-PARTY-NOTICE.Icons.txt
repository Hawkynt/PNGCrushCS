Third-party artwork shipped with Crush.Viewer
=============================================

The icons under this directory were not drawn for this project. They come from five
published sets, unchanged, and each carries its own licence. Every one of those
licences requires that the notice travel with the artwork, which is what this file
is for. Each set's own licence statement is beside its files as LICENSE.txt.

Why these sets
--------------

Silk is the mid-2000s Windows look the viewer is going for and covers a picture
browser's whole vocabulary, but it exists only at 16x16, which is the size the
ribbon's small items and the status bar draw at. The ribbon's large items draw at
32x32, so they are Oxygen's, which is the same era's glossy style at that size
under a licence this repository can absorb without a second thought.

Where neither has an honest glyph, the next sets were searched in this order: Silk
Companion, which is Silk extended by another hand; Fugue, which is drawn in the
same style at the same size; and FatCow, which is Silk-style at both 16x16 and
32x32. The first that draws the command as itself is the one used.

No icon is scaled up: each is used at the size it was drawn for, and a 32x32 icon
borrowed for a 16x16 slot is box-filtered down rather than sampled.

Commands with no honest icon in any of the five are left as text rather than given
a glyph that means something else: the three signal standards among the display
filters (NTSC composite, NTSC S-Video, PAL), the resampling kernels (Lanczos,
Mitchell, Catmull-Rom, area average), the pixel-art doubling rules (Scale2x, Eagle,
xBR), unsharp mask, denoise, emboss, edge detect, solarise, sepia and duotone.
