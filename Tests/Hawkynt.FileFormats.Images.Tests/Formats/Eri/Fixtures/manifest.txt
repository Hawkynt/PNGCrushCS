ERI fixtures and what produced them
===================================

Every picture here is synthetic, made for this repository: 37x23 gradients with noise, the same
with an opacity ramp, a grey ramp, a 16-colour indexed picture, an RGB555-exact picture, and short
animations of a moving square. None is a third-party image.

The references are the two Entis libraries, built for Linux x86-64 from their published sources
with the portability fixes listed below, and the 2001 Windows converter ericvt.exe run under wine:

  sa_*   written by ERISA-Library 1.07 (Leshade Entis, 2003-2004; olesya-wo's portable fork)
  na_*   written by ERINA-Library 1.0A (Leshade Entis, 2000-2002)
  ours_* written by this repository's EriWriter

  <name>_<n>.pam   the reference decoder's frame n: top row first, R G B (A) or GRAYSCALE
                   (palette indices for a paletted picture)
  <name>_<n>.pal   the 256 palette entries the reference decoder read, 4 bytes each, B G R x

sa_* and ours_* are decoded by ERISA; na_* and ours_pal8 (the 256-colour RL-MTF-G code, which
ERISA does not read) by ERINA. Every lossless fixture decodes byte-for-byte the same in both
libraries wherever both read it, and in ericvt.exe wherever it reads it (it has no ERISA code and
no opacity); every ours_* file decodes in all three to exactly the picture it was written from.

Lossy (sa_lossy_*, ERISA's version-28H DCT format): the library's portable C decoder had to be
corrected to do what its shipped assembly does -- coefficients de-interleaved, matrix scale 2/N,
scale exponent by arithmetic shift, signed clamp, rounding ties to even -- and the decodes here are
from that corrected decoder. Its float transform sums in its own order, so a sample may land one
off; the shipped assembly uses a 16-bit fixed-point transform, which no available tool runs.

refused_* are files the libraries wrote that no available decoder gives back faithfully, which the
reader refuses by name: a LOT picture (ERISA's own decoder does not return what its encoder was
given), an ERINA version-9 lossy picture, a motion-compensated MEI, and an ERINA version-8 picture
with run-length gamma symbols (ERINA writes it but cannot read it back; ERISA reads garbage).

Commands (paths relative to the scratch build): erisa_cli / erina_cli
  encode <src.pam> <out.eri> --arch gamma|huffman|nemesis --version 0x00020100|0x00020200
         --format rgb24|rgba32|rgb32|gray8|pal8|rgb16 [--pal pal16.pal] [--blocking N]
         [--topdown] [--dependent|--independent] [--lossy dct --sampling 444|411 --preset N]
         [--copyright T --description T]
  encode-anim <out.mei> <keyframe> <frame0.pam> ...
  decode <in> <prefix>
